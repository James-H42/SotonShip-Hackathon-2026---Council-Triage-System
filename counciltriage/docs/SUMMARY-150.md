# StreetTriage in 150 words

StreetTriage helps Southampton City Council deal with street problems like potholes,
fly-tipping and broken lights faster and more fairly. Residents report a problem
in under a minute: they pick the issue, drop a pin on a map (or let their photo's location do it),
and describe it. Before sending, a local AI checks whether someone has already reported the
same problem. If so, the resident joins that report and can add details, giving the council one
stronger report, not duplicates. For council officers, every report is read by a local
language model and every photo is checked by an image model. Each is ranked by risk:
severity, injuries, vulnerable people, busy roads and how many people reported it. Officers get a
prioritised queue, a colour-coded map and grouped incidents. They update progress, and the system
plans efficient repair routes. Everything runs on council hardware: residents' data never
leaves the council.
